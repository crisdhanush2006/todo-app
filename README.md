# My To-Do List App

A simple, responsive To-Do List web app, built twice: once with vanilla HTML/CSS/JavaScript and once with React (Vite).

## Features
- Add new tasks
- Mark tasks as done (click to toggle strikethrough)
- Edit tasks (double-click)
- Delete tasks
- Filter tasks: All / Active / Done
- Live counter of remaining tasks
- Tasks persist after page refresh (localStorage)

## Tech Stack
- Vanilla version: HTML5, CSS3 (Flexbox), JavaScript (DOM manipulation, localStorage API)
- React version: React, Vite, useState, useEffect

## Project Structure
- Root folder: vanilla JS version (`index.html`, `style.css`, `script.js`)
- `todo-react/`: React version

## How to Run
Vanilla version:
1. Clone this repository
2. Open `index.html` in your browser (or use Live Server in VS Code)

React version:
1. Clone this repository
2. `cd todo-react`
3. `npm install`
4. `npm run dev`
